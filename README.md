# YANDIK+

**Satu data, pelayanan kesehatan hewan lebih tertata.**

**YANDIK+** adalah inisiatif pengembangan sistem kerja digital terpadu untuk mendukung pelayanan kesehatan hewan dan pengelolaan Pusat Kesehatan Hewan (Puskeswan) di Sumatera Barat.

YANDIK+ dirancang untuk menghubungkan **profil Puskeswan, SDM veteriner, pelaporan pelayanan (APEL), pengawasan, serta permasalahan dan tindak lanjut** dalam alur kerja yang sederhana, terukur, dan mudah ditelusuri.

## Hasil yang Dituju

- **Petugas:** pencatatan dan pelaporan lebih praktis, tanpa pengisian data berulang.
- **Pengelola:** kondisi fasilitas, kebutuhan, dan tindak lanjut lebih mudah dipantau.
- **Pimpinan:** dashboard informasi untuk mendukung evaluasi, pembinaan, dan perencanaan.

**Status:** YANDIK+ terpadu masih dikembangkan secara bertahap. Sebagian layanan APEL sudah berjalan secara terpisah. Sistem ini tidak menggantikan keputusan maupun prosedur resmi yang berlaku.
