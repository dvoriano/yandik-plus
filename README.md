**Kerja sudah sulit, administrasi jangan rumit.**

## Cara bekerja
1. Baca status pada ROADMAP.md.
2. Buka dokumen modul yang akan dikerjakan.
3. Buat issue/branch dan perbaiki kode memakai data dummy.
4. Jalankan tes dan PR review; baru perbarui status jika kriteria selesai terpenuhi.
5. Sebelum ada dana, persetujuan dan staging, jangan deploy ke website aktif.

**Repository ini terpisah sepenuhnya dari bot Indodax.**
