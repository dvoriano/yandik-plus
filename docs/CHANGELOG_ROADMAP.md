## Format pembaruan berikutnya
Gunakan satu baris baru pada tabel di atas dan detail bila berdampak besar:

- **ID keputusan:** DEC-YYYYMMDD-NN
- **Jenis:** TAMBAH / UBAH / HAPUS / TUNDA / AKTIFKAN_KEMBALI
- **Modul dan milestone terdampak**
- **Sebelum → Sesudah** (untuk perubahan)
- **Alasan, manfaat, risiko, dependensi**
- **Persetujuan/penanggung jawab** (jika perlu)
- **Link issue/PR dan tanggal berlaku**

## Aturan hapus
- Hapus dari tabel rencana aktif **hanya setelah** keputusan tercatat.
- Jangan menghapus log, commit, bukti, laporan historis atau definisi indikator yang sudah digunakan.
- Bila modul diganti nama, pertahankan ID lama sebagai alias dan arahkan ke nama baru.
- Aturan APEL historis tidak boleh diam-diam diubah; revisi diterapkan lewat versi per tahun/periode.
