# Katalog Modul YANDIK+

Semua modul memiliki **dokumen tersendiri**, bukan satu spesifikasi raksasa. Status pengembangan yang berlaku hanya di [ROADMAP.md](ROADMAP.md).

| Kode | Modul | Kondisi dari snapshot | Dokumen |
|---|---|---|---|

| MOD-02 | APEL Puskeswan | Pelaporan, dashboard dan template sudah ada | [APEL](modules/02_APEL_PUSKESWAN.md) |
| MOD-03 | SDM Veteriner | Direktori/fitur SDM awal tersedia | [SDM](modules/03_SDM_VETERINER.md) |
| MOD-04 | Support Puskeswan | Data kebutuhan dasar; alur bantuan perlu dibangun | [Support](modules/04_SUPPORT_PUSKESWAN.md) |
| MOD-05 | Pengawasan Obat Hewan | Kerangka kode / halaman awal | [Obat Hewan](modules/05_PENGAWASAN_OBAT_HEWAN.md) |
| MOD-06 | Klinik dan Praktik Dokter Hewan | Kerangka kode / halaman awal | [Klinik/Praktik](modules/06_KLINIK_PRAKTIK_DOKTER_HEWAN.md) |
| MOD-07 | PHMS, Zoonosis & Surveilans | Integrasi/ide perlu dikembangkan | [PHMS](modules/07_PHMS_ZOONOSIS.md) |

| MOD-10 | Administrasi Kegiatan & Dokumen | Form dan dokumen parsial; perlu workflow bersama | [Dokumen](modules/10_ADMINISTRASI_DOKUMEN.md) |
| MOD-11 | Dashboard Pimpinan | Dashboard APEL ada; lintas modul belum terbangun | [Dashboard](modules/11_DASHBOARD_PIMPINAN.md) |
| MOD-12 | GIS Kesehatan Hewan | Lokasi awal tersedia; layer lintas modul belum | [GIS](modules/12_GIS.md) |

**Cara baca:** kolom kondisi mendeskripsikan hasil temuan snapshot parsial, **bukan** klaim modul selesai atau berjalan di produksi. Pengembangan nyata akan direkam per milestone/issue.
