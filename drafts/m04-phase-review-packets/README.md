- `packets.mjs` menggabungkan urutan baca DEMO M04-S9P dan pertanyaan/bukti DEMO M04-S9M ke **empat paket fase P0–P3**.
- Keempat paket mencakup seluruh 18 butir dan seluruh pertanyaan yang belum dijawab. Tiap butir menyimpan nomor urutan baca sumber, pendahulu, kebutuhan bahan, catatan kekurangan dan usulan fiktif, serta kategori fungsi penyiap/penelaah **usulan**.

- Sumber 3 catatan kekurangan DEMO fiktif, 15 tidak berisi catatan contoh; **bukan temuan audit atau status bukti riil**.
- Semua paket **belum dikirim/dijadwalkan/dibahas secara resmi**; seluruh jawaban dan keputusan resmi kosong, bukti belum diverifikasi, penugasan/QA/deploy tidak diizinkan.
- Antarmuka baca-saja memberi filter fase dan fungsi, rangkuman per fase, pertanyaan terbuka dan rekap teks tanpa API, storage, fetch, backend, tanda tangan atau pengiriman.
