# M04-I3 | Penelusuran dampak dan cabang rekonsiliasi DEMO

**KODE DITULIS, BELUM DIUJI.** Model `impact.mjs` menerima sumber sintetis dari kontrak I2, membandingkan kebutuhan/versi/isi sumber, lalu menelusuri paket → telaah → jadwal → kirim → terima → rujukan BAST → monitoring.

Rancangan membuat cabang kerja prospektif terpisah; objek yang terdampak tidak dihapus dari workspace aktif atau histori I2. Dalam cabang prospektif, hanya catatan terdampak yang dikeluarkan agar model bisa diperiksa ulang; IDs dan snapshot aslinya tetap terdaftar dalam manifest dampak. Paket lintas fasilitas diblokir dan memerlukan pembahasan manual. Tidak ada penerbitan dokumen atau pengubahan produksi.

Cabang hanya untuk telaah teknis DEMO, **bukan izin aktivasi atau keputusan kelembagaan**. Tes belum dijalankan. Lihat `docs/M04_I3_RECONCILIATION.md` untuk batasan dan rencana pemeriksaan.
