# M04-S13–S15 | Siklus realisasi sampai pemanfaatan

**KODE DITULIS, BELUM DIUJI.** Tiga model murni dan satu antarmuka terpadu DEMO. Fixture S10–S12 tetap fiktif dan tidak menerima hasil edit halaman sebelumnya. S13 membatasi kirim/terima dan membedakan baik, rusak, belum diterima; S14 menautkan metadata rujukan per fasilitas (model mendukung beberapa penerimaan, UI satu per catatan); S15 membagi barang baik menjadi digunakan, belum digunakan, rusak setelah penerimaan. Ringkasan hanya memakai pengamatan terbaru per baris dan per satuan. Semua catatan append-only dalam memori, reset menghapus semuanya. Koreksi, rekonsiliasi sumber usang, otorisasi dan integrasi riil belum tersedia.
