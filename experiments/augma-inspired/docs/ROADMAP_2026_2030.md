# Roadmap eksperimen YANDIK+ Innovation Lab (2026–2030)

**Jalur penelitian terpisah.** Tidak menggantikan roadmap utama YANDIK+; tidak mengubah APEL dan server produksi. Tahun adalah horizon evaluasi, bukan janji integrasi.

## 2026 (Fondasi dan prototipe)

- [x] Branch eksperimen khusus dan aturan tidak menyentuh `main`, `develop`, produksi.
- [x] Katalog ide Augma: visual interaktif, peta situasional, tanya-data, 3D.
- [x] Dashboard awal dengan data sintetis.
- [x] Geo Command Center: outline geografis Sumbar dan 19 penanda lokasi indikatif.
- [x] Evidence Assistant: antarmuka mandiri + logika jawaban bersumber, **belum LLM**.
- [x] Dokumentasi sumber peta, lisensi, status data, dan batas pengembangan.
- [ ] Uji visual dan fungsional pada browser nyata, ponsel, dan STB.
- [ ] Verifikasi lebih lanjut koordinat pusat wilayah dan ketelitian geometri.

## 2027 (Kualitas data dan UX)

- [ ] Sediakan poligon ADM2 dari sumber GIS tervalidasi untuk seluruh kabupaten/kota, dengan metadata tanggal/versi/lisensi.
- [ ] Validasi pemetaan kode wilayah ke dataset uji yang disetujui.
- [ ] Uji tugas petugas/pengelola: cari wilayah, data belum lengkap, dan prioritas tindak lanjut.
- [ ] Aksesibilitas keyboard, kinerja perangkat murah, dan penyajian offline.

## 2028 (Kontrak data uji)

- [ ] Skema read-only untuk ringkasan data (tanpa koneksi produksi langsung).
- [ ] Otentikasi, RBAC, audit, batas permintaan, masking/anonymization.
- [ ] Validasi angka `null`, `0`, `stale`, dan `verified` sebagai status yang berbeda.

## 2029 (Asisten AI dengan bukti)

- [ ] Rancang dan evaluasi adapter LLM lokal/terisolasi (bila perangkat dan izin memungkinkan).
- [ ] Retrieval dari sumber yang diberi izin, verifikasi kutipan, pengujian halusinasi.
- [ ] Blokir permintaan sensitif, aksi otomatis, dan pengungkapan tidak sah.
- [ ] Benchmark akurasi berdasarkan pertanyaan nyata sebelum masuk produksi.

## 2030 (Keputusan adopsi)

- [ ] Audit manfaat vs biaya dan risiko; lanjutkan/hentikan tiap komponen secara terpisah.
- [ ] Telaah tata kelola, interoperabilitas, akses, dan pemilik layanan sebelum integrasi yang disetujui.
- [ ] Evaluasi eksperimen 3D/gestur hanya jika kebutuhan pengguna terbukti.

## Gerbang penerapan

Fitur **tidak otomatis** masuk sistem operasional. Wajib bukti nilai kerja, ketepatan data, kepatuhan lisensi, keamanan, kebijakan SPBE terkait, biaya operasional, owner, dan rollback. Integrasi memerlukan izin eksplisit.
