# Roadmap eksperimen YANDIK+ Innovation Lab (2026–2030)

**Terpisah dari roadmap utama** dan tidak mengubah APEL, VPS, atau branch `main`/`develop`. Tahun adalah horizon evaluasi, bukan janji pengoperasian.

## 2026: dasar prototipe

- [x] Jalur eksperimen sendiri `lab/augma-inspired-experiments`.
- [x] Radar riset Augma dan guardrail lisensi.
- [x] Command Center awal menggunakan seluruh angka simulasi.
- [x] Geo Command Center dengan outline provinsi dan 19 penanda indikatif.
- [x] Loader impor ADM2 pada browser: cek 19 identitas, Polygon/MultiPolygon dan geometri dasar.
- [x] Daftar kandidat sumber ADM2, catatan risiko ketelitian dan izin.
- [x] Evidence Assistant dengan bukti sumber dan penolakan angka yang belum ada.
- [x] Adapter model lokal melalui CLI hanya opt-in, output review-only.
- [x] Skrip tes unit dan skrip tes browser manual.
- [x] Dashboard pelaporan 19 unit **fiktif** × 12 bulan (228 catatan), KPI dan tren, filter, detail, daftar tindak lanjut, CSV sintetis.
- [x] 22 pemeriksaan logika JavaScript dijalankan dalam evaluasi terisolasi dan lulus; **bukan** pengujian browser.
- [x] Skrip Playwright khusus dashboard simulasi ditambahkan (hasil browser belum terverifikasi).
- [x] Perhitungan GeoJSON bounds tanpa penyebaran array besar, dengan tes regresi 150 ribu titik (belum dijalankan pada Node checkout repo).
- [x] Audit geometri offline dengan Shapely untuk kode duplikat, poligon invalid, overlap, dan selisih outline (hasil teknis saja).
- [x] Enam regresi auditor Shapely lulus menggunakan poligon **sintetis** (23 November 2026), termasuk penolakan selisih terhadap outline di atas 10%.
- [x] Skrip pengujian browser responsif, akses eksternal, dan pengukuran awal; belum dijalankan pada aplikasi nyata.
- [x] Diagnostik STB baca-saja; belum dijalankan pada STB fisik.
- [x] Pengambil data kandidat ADM2 BNPB berbasis HTTPS, read-only, dipanggil manual, cocokkan objectId tiap batch dan cek ulang snapshot, fail-closed; kode sumber tidak diintegrasikan ke produksi.
- [x] Workflow GitHub Actions terbatas pada branch lab untuk tes offline GIS dan browser, tanpa izin tulis atau deployment.
- [x] Tambahkan gerbang isolasi source: deteksi perubahan di luar lab, symlink, file rahasia, dan domain produksi.
- [x] Tambahkan 6 tes unit untuk aturan isolasi (kode tersedia, eksekusi CI belum terverifikasi).
- [x] Integrasikan tiga job CI dengan dependency isolasi sebelum GIS dan browser, serta simpan laporan Playwright ketika gagal.
- [x] [Status QA dan persyaratan kelulusan](QA_GATE_STATUS_2026-11-23.md).
- [ ] Konfirmasi hasil workflow GitHub Actions dan perbaiki kegagalan yang teramati.
- [x] Sembilan skenario pengujian mock untuk pengambil BNPB disiapkan, termasuk kecocokan fid dan perubahan daftar ID (hasil eksekusi CI belum diverifikasi).
- [ ] Jalankan pengambilan kandidat geometri BNPB dengan izin dan lingkungan jaringan yang mendukung, serta tinjau status teknisnya.
- [x] [Catatan bukti dan keterbatasan pengujian](../VALIDATION_EVIDENCE_2026-11-23.md).
- [ ] Menjalankan pengujian antarmuka nyata dan mencatat hasil pada desktop/HP.
- [ ] Mengumpulkan GeoJSON ADM2 19 wilayah dari sumber berizin + verifikasi GIS.
- [ ] Memeriksa performa pada STB/laptop uji sebenarnya.

## 2027: geometri dan kegunaan

- [ ] Selesaikan verifikasi geometri 19 kabupaten/kota, provenance, topologi, datum dan versi.
- [ ] Audit peta Mentawai dan daerah perbatasan, cek gaps dan overlaps.
- [ ] Uji kemudahan alur petugas dan pengelola, aksesibilitas, koneksi buruk.

## 2028: data uji dan keamanan

- [ ] Tentukan kontrak API read-only untuk data uji berizin.
- [ ] Pengendalian identitas, peran, log audit, masking data, dan batas permintaan.
- [ ] Indikator membedakan `null`/`zero`/`stale`/`verified`.

## 2029: AI berbukti

- [ ] Evaluasi LLM lokal dengan dokumen yang diizinkan dan pencantuman sumber.
- [ ] Uji konsistensi numerik, halusinasi, prompt injection, salah rujukan, serta privasi.
- [ ] Tolak tindakan otomatis dan jawaban administratif tanpa wewenang.

## 2030: tinjau keputusan adopsi

- [ ] Evaluasi manfaat dan biaya; pilih lanjut, revisi, atau hentikan setiap komponen.
- [ ] Kajian kelembagaan, kepatuhan SPBE yang relevan, perizinan, operasi dan rollback.
- [ ] 3D/gestur hanya jika terbukti berguna dan terjangkau.

## Gerbang utama

Tidak ada integrasi otomatis. Perlu persetujuan eksplisit dan audit keamanan, lisensi, akurasi sumber, kegunaan, serta tata kelola sebelum dipertimbangkan ke produksi.
