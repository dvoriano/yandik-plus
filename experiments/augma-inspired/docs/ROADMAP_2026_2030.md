# Roadmap eksperimen terisolasi (2026–2030)

Roadmap ini **terpisah** dari roadmap operasional YANDIK+ dan pekerjaan APEL. Tahun adalah horizon evaluasi, bukan janji go-live.

| Fase | Fokus | Keluaran yang diuji | Gerbang keputusan |
|---|---|---|---|
| 2026 Q4 | Inventaris teknologi, pembatasan lisensi, PoC dashboard | Radar, guardrail, command center data sintetis | PoC berjalan sendiri; tidak menyentuh main/develop |
| 2027 | Validasi visualisasi dan kegunaan | Uji tugas pengguna, desain responsif, mock skema data | Setiap indikator punya definisi dan sumber |
| 2028 | Percobaan integrasi baca data *di lingkungan uji* | API mock, kontrol peran, log audit, pengujian keamanan | Tidak ada kredensial/akses langsung ke produksi |
| 2029 | Asisten tanya-data dengan bukti sumber | Jawaban tersitasi ke catatan uji, penolakan jika data tak ada, evaluasi akurasi | Uji privasi, halusinasi, performa, dan otorisasi |
| 2030 | Evaluasi adopsi terpilih / 3D opsional | Keputusan lanjut/hentikan tiap komponen; panduan operasional | Persetujuan tata kelola; kebutuhan pengguna terbukti |

- [ ] Pertimbangkan peta sebenarnya setelah koordinat dan izin sumber diverifikasi.
- [ ] Pertimbangkan uji Three.js/WebXR bila kebutuhan edukasi jelas.

## Kebijakan promosi

Tidak ada `merge`, `pull request`, `deploy`, atau pemakaian database produksi secara otomatis. Integrasi ke jalur utama memerlukan review dan persetujuan tersendiri. Cabang lab boleh dibuang tanpa merusak YANDIK+ utama.
