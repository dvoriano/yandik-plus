# Guardrail sumber, lisensi, data, dan penerapan

## Status sumber eksternal

Katalog https://repo.augmaimaginarium.com/ memuat Holo-Explorer dengan stack **Three.js** dan keterangan lisensi **CC BY-NC 4.0** (diamati 23 November 2026). Akses untuk membaca/mengunduh source di katalog mensyaratkan registrasi Google. Halaman portofolio Augma bukan bukti semua proyek menyediakan source bebas pakai.

**Tindakan saat ini: tidak menyalin kode, aset, gambar, audio, model 3D, ikon, teks kreatif, atau tampilan identik dari Augma.** Riset ini hanya mengadopsi ide umum: visual interaktif dan pertanyaan atas data.

Lisensi bertanda NC melarang jenis pemanfaatan komersial tertentu. Jangan menyimpulkan bahwa semua penggunaan instansi pemerintah otomatis aman. Bila ingin memakai materi mereka, periksa lisensi pada file konkret, syarat atribusi, keterbatasan penggunaan, kebutuhan izin, serta ketentuan pengadaan/tata kelola yang relevan. CC sendiri tidak merekomendasikan CC sebagai lisensi perangkat lunak.

## Pemisahan dari pekerjaan utama

- Branch `lab/augma-inspired-experiments` tidak digabung ke `main` atau `develop` tanpa review.
- Semua prototipe hanya menggunakan data sintetis. Data simulasi tidak boleh dipublikasikan sebagai capaian nyata.
- Tidak menyentuh `yandikvo.my.id`, database produksi, VPS, konfigurasi systemd, maupun token.
- Integrasi kelak lewat kontrak data yang diverifikasi, baca-saja sesuai kewenangan, dengan audit dan pembatasan permintaan.
- AI/fitur tanya-data tidak boleh mengambil keputusan administratif otomatis atau menerbitkan pernyataan resmi.
- Tidak mengaktifkan webcam tanpa tindakan sadar pengguna; jika diuji nanti, pemrosesan lokal dan tanpa rekaman secara default.
- Tidak ada auto-deploy, GitHub Actions berakses rahasia, atau dependensi telemetri tersembunyi dalam lab ini.

## Keluar dari lab

Promosi fitur mensyaratkan setidaknya: bukti kegunaan, kepatuhan lisensi, pengujian keamanan, validasi data, aksesibilitas, kemampuan rollback, pemilik operasional, serta otorisasi penerapan. Bila tidak layak, cukup arsipkan eksperimennya.
